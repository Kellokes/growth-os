Editor de caixas

Adicione só as caixas que o layout precisa (um Reels pode ficar sem texto, e a imagem é opcional) e arraste cada uma para onde deve ficar na arte. Puxe o canto para mudar o tamanho. O texto de exemplo mostra o limite de caracteres de cada caixa.

Nenhuma caixa neste layout. Use "Adicionar" para criar o título, o texto ou a imagem.
